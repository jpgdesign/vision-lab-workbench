# 辦公室攝影機：進出與坐姿規則

選擇 **「辦公室攝影機：進來／出去＋坐姿」** 模板（`live-office-crossing`）。流程為 YOLO26n Pose → 同來源人物追蹤 → 跨線／坐姿規則 → 畫面與事件輸出；來源可改成已匯入影片、USB／虛擬攝影機或 VDO.Ninja。

先取得姿態模型；這個模板不需要下載 ST-GCN++：

```powershell
python download_workflow_models.py --models pose --download
```

## 中線與左右方向

預設直線位於畫面水平位置 `0.5`，涵蓋整個高度。同一追蹤人物的框中心從左側跨到右側記為 **出去**，從右側跨到左側記為 **進來**。新人物第一次出現只建立初始側別，不會直接當作跨線事件；忽略帶、最小位移與持續時間用來降低中線附近抖動造成的重複計次。

**左右以實際送入模型的影像為準。** 手機前鏡頭、虛擬攝影機、串流工具或前處理可能使用鏡像；預覽的自拍效果也未必等於送出的畫面。部署前請實際各走一次左→右與右→左，確認標示符合場地定義；改變鏡像或鏡頭方向後重新驗證。

在原生應用工作檯選取「辦公室 · 進出計數與坐姿規則」節點，右側「設定進出判定線」可點擊／拖曳直線、拖動滑桿或按「置中」。可用左右方向鍵微調，Shift＋方向鍵每次移動 5%。有參考圖片／影片時沿用素材比例，沒有素材時可先設定相對位置。即時鏡頭仍需在實際結果畫面確認線的位置。

這裡的判定線是可調整水平位置及上下端點的**垂直線段**，不是任意斜線。線段外的移動不算跨越這條線。一般同來源追蹤不能保證遮擋後仍是同一個人，也不提供跨鏡頭身份辨識。

## 在 ComfyUI 調整

開啟中文名稱的辦公室工作流，在 `VisionWB_office_monitor` 節點設定下列欄位。來源節點 `source_mode` 選 `camera` 或 `vdo`，執行後在輸出節點的即時檢視器連接來源並開始。載入流程不會自動開攝影機；修改參數後重新執行，讓新的設定套用到新流程快照。

| 欄位 | 預設 | 意義 |
|---|---:|---|
| `line_x` | `0.5` | 中線距離畫面左邊的比例，0 左、1 右；需留出忽略帶空間 |
| `line_y_start`／`line_y_end` | `0`／`1` | 線段上端／下端，依畫面高度正規化 |
| `hysteresis` | `0.025` | 中線左右各佔畫面寬度 2.5% 的忽略帶 |
| `min_travel` | `0.08` | 跨側確認所需的最小水平位移比例 |
| `side_dwell_seconds` | `0.15` | 在另一側穩定出現的確認時間 |
| `cooldown_seconds` | `1.5` | 同一人物的跨線事件最小間隔 |
| `max_gap_seconds` | `1` | 連續觀察容許的最大影格間隔；超過後不把中斷兩端直接接成跨線 |
| `keypoint_confidence` | `0.5` | 坐姿判定使用的關節信心下限 |
| `sitting_dwell_seconds` | `1` | 坐姿候選需持續的時間 |
| `seated_label` | `認真（坐姿規則）` | 使用者自訂的坐姿顯示名稱 |
| `posture_mode` | `strict_full_body` | 節點預設為完整骨架規則；新辦公室模板選用 `occlusion_assisted` 遮擋輔助模式 |
| `zones` | `[]` | 0–8 個坐姿肩部校正區域；每個包含 `name` 與正規化 0–1 座標 `points` |
| `occluded_dwell_seconds` | `2` | 遮擋候選的持續觀察時間（秒） |
| `require_sit_transition` | `False` | 是否額外要求同一追蹤人物先出現可信站姿，再有肩部下降；預設關閉 |
| `sit_drop_ratio` | `0.06` | 啟用坐下過程要求時，肩部下降需達畫面高度的比例 |
| `max_pose_drift` | `0.06` | 遮擋輔助允許的肩部位置漂移，以影像對角線比例計算 |

## 坐姿與未知狀態

「認真（坐姿規則）」是使用者指定的名稱，實際依可見關節、二維姿態幾何與持續時間判斷，**不推斷專注程度、心理狀態或工作表現**。可將 `seated_label` 改成「坐姿候選」等適合場景的名稱。

| 模式 | 使用的證據 | 適合情況與限制 |
|---|---|---|
| `strict_full_body` 完整骨架 | 可信且可見的左右肩、髖、膝、腳踝，加上姿態幾何與持續時間 | 沿用原本規則；腿部被遮住時回報姿態不明 |
| `occlusion_assisted` 遮擋輔助 | 腳踝不可見時，使用可見的肩、髖、膝；髖與膝也不可見時，需校正肩部區域、可信的雙肩與頭部參考點，並持續維持穩定位置 | 適合固定鏡位下的桌面遮擋。遮擋證據顯示 **「認真（坐姿規則）· 遮擋候選」**，不當成已確認坐姿 |

看似合理但低信心的關節不當作證據；區域內沒有可信人物骨架也不會因為有椅子就判成坐姿。二維幾何可能與蹲姿、彎腰相似，肩部區域也可能被站立者或路過者佔據，因此仍需在實際鏡位檢查誤報。若可見關節不足、沒有必要的校正區域或未達持續條件，保留姿態不明。

### 三步設定桌面遮擋

1. 選取「辦公室 · 進出計數與坐姿規則」節點，將 `posture_mode` 選為 `occlusion_assisted`。新辦公室模板已選此模式，舊流程不會被自動改成新模式。
2. 在素材選單選擇**同一鏡位、相同鏡像設定、有人坐下**的參考圖片。於節點的「在畫面上定義區域」按「新增區域」，以至少三個點圈出**坐下時雙肩中點可能落入的小範圍**，命名如「右側座位肩部」並按「儲存區域」。區域是肩部位置的容許範圍，不是整張椅子、桌面或人物外框；多個座位分別設定，最多八個。ComfyUI 可在 `zones` 輸入相同的區域 JSON；座標 x、y 分別除以影像寬、高。
3. 切回原本攝影機／VDO.Ninja 來源並重新執行流程，檢查坐下、站立、路過、彎腰及遮擋時的結果。先沿用 `occluded_dwell_seconds=2`；若要增加「先站立再坐下」的證據，可啟用 `require_sit_transition`，並調整 `sit_drop_ratio`。這項條件需要同一追蹤 ID 的連續觀察；一開始就坐著的人不會有站立歷史。`max_pose_drift` 控制位置穩定度，應依實際誤報調整，而非僅為增加判定數量而放寬。

校正區域不會自動從椅子或單張照片學出坐姿。換鏡位、調整縮放或鏡像後，需重新校正並各測一次站立與坐下；多人互相遮擋、追蹤 ID 改變時，不沿用另一個人的坐下歷史。

換來源、重新開始或追蹤中斷時會重建相關狀態。計數屬於本次流程觀察，不是長期門禁或出勤紀錄。驗證時應比較人工記錄的跨線方向與次數，並包含中線徘徊、多人遮擋、腿部不可見及鏡像情況。

攝影機連接方式見 [ComfyUI 整合說明](comfyui-integration.md#同一支攝影機接多個模型)；其他模型組合見 [洗手工作流模型說明](handwashing-models.md)。
